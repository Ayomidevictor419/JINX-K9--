𝙅𝙄𝙉𝙓 𝙆9 V1 AI CONFIG (Free public gateway mode)

No personal API key required for basic AI chat.

Commands:
  .ai <question>         -> automatic free-gateway fallback
  .gpt / .openai         -> OpenAI-style free route
  .gemini                -> Gemini-style free route
  .deepseek              -> DeepSeek-style free route
  .mistral               -> Mistral-style free route
  .llama                 -> Llama/Qwen free route
  .coder                 -> Coder model free route
  .polli / .pollinations -> Pollinations free route
  .aistatus              -> shows AI mode
  .imagine <prompt>      -> free image generation
  .chatbot on|mention|off|reset

How it works:
  𝙅𝙄𝙉𝙓 𝙆9 tries public free AI gateways first (using shared public AI gateways).
  If you later add OPENAI_API_KEY / GEMINI_API_KEY / etc. in config.env,
  those official keys are preferred when available, then free fallback.

Note: Free public gateways can be rate-limited or temporarily down.
If .ai fails, wait a bit and try again.
